# User guide

## Signing in
Open the site, enter e-mail and password. "Forgot password?" sends a reset link (see README for the e-mail limitation).
Use the **EN / KH** switch and the sun/moon button in the top bar at any time – both apply instantly and are remembered.

## Administrator
1. **Setup order:** Settings → add an academic year and semester → Classes → add classes → Students (add one by one, or *Import CSV / Excel*) →
   open *Students & schedule* on a class to enrol students and add the weekly timetable → Class Monitors → create a monitor per class.
2. **Import:** columns `studentCode, fullName, email, gender, phone, classCode`. Temporary passwords are shown once – download them from the result dialog.
3. **Attendance Overview:** filter sessions, open one, and correct a locked record (pencil). A reason is mandatory; the change is audited and the student is notified.
4. **Corrections:** approve/reject requests. **Reports/Analytics:** filter, then export PDF/Excel/CSV.
5. **System Settings:** school name, timezone, *late after N minutes*, how *excused* sessions count in the percentage, minimum attendance %.
6. **Users / Audit Logs:** reset passwords, (de)activate accounts, review every sensitive action and sign-in.

## Class Monitor
1. **Take Attendance** → choose date, session number (and optional start time for the late rule) → *Start session*. If it already exists you are taken to it.
2. Tap a status for each student; add check-in time or remarks. *Mark unmarked as present* helps with large classes. **Save draft** any time.
3. **Submit & lock.** Unmarked students become *Absent*. After this you cannot edit – use **Attendance History → open session → clock icon** to request a correction (admin approves).
4. Review student requests under **Corrections**. Publish class **Announcements** (if permitted). **Reports** export your class data.

## Student
Dashboard shows percentage, counts and recent history (a warning appears below the minimum). **Calendar** shows each day; click a coloured dot or use
**History → clock icon** to request a correction with a reason. **Schedule** shows your weekly timetable. **Profile** lets you change phone/address; **Settings** language, theme, password.

## Colours
Green = Present · Amber = Late · Red = Absent · Blue = Excused.
